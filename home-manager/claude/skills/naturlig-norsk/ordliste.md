# Ordliste — kansellistil og anglisismer

Referansemateriale for `naturlig-norsk`. Bruk listene som søkemønstre i kritikk-modus og som filter i utkast-modus. Listene er ikke uttømmende — match prinsippet, ikke bare ordet.

## Kansellistil → klart språk

| Unngå | Bruk heller |
|-------|-------------|
| angående | om |
| vedrørende | om, når det gjelder |
| beliggende | som ligger |
| foreligge | finnes, være |
| idet | da, fordi |
| hvorvidt | om |
| såvel ... som | både ... og |
| tilkjennegi | vise, gi uttrykk for |
| medføre | føre til |
| hensynta | ta hensyn til |
| iverksette | sette i gang |
| gjeldende | som gjelder |
| erverve | få, skaffe |
| anmode | be om |
| oversendes | sendes |
| avstedkomme | føre til, skape |
| beslutte iverksatt | beslutte å gjennomføre |
| fortrinnsvis | helst |
| i henhold til | etter, i tråd med |
| innbefattet | medregnet, inkludert |

**Unntak:** I juridisk eller forskriftsnær tekst kan flere av disse være etablerte termer — behold dem hvis registeret krever det. Regelen er ikke å rense alt automatisk, men å unngå kansellistil der den ikke har funksjon.

## Anglisismer → norsk

| Unngå | Bruk heller |
|-------|-------------|
| implementere | innføre, gjennomføre |
| requirement | krav |
| approach | tilnærming, fremgangsmåte |
| feature | funksjon, egenskap |
| stakeholder | interessent |
| deadline | frist |
| input | innspill, inndata |
| output | resultat, utdata |
| scope | omfang |
| feedback | tilbakemelding |

**Unntak:** Fagtermer som er etablert på engelsk i bransjen (f.eks. «API», «backend») skal stå. Skill mellom unødvendige anglisismer (der norsk ord finnes og er like presist) og fagtermer (der oversettelse forvirrer leseren).
